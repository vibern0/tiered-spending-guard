## Approved scope

Handler/profile changes are delayed maintenance operations. The older stock-module, nested-owner-call, ECDSA-secondary, and funder-deposit direction is superseded.

No native handler, protocol, or account-abstraction code was implemented in this prerequisite task. `apps/backend` remains required until the native replacement passes provider, browser, monitoring, and live gates.
